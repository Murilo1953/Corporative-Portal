System Display Pages

The System Display is normally presented on the lower ECAM display unit. It provides 11 system pages with aircraft-system synoptics, plus STATUS; CRUISE is automatically displayed in flight.

ENGBLEEDPRESS ELECHYDFUEL APUCONDDOOR/OXY WHEELF/CTL
Use: each SD page can be called manually with the corresponding pushbutton on the ECAM Control Panel. Each figure below is displayed directly. The “Displayed information” references are numbered to correspond with the figure callouts.
