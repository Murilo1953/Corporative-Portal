Alpha Call-Up List

The FDIMU/DMU receives parameters from multiple aircraft systems over ARINC 429 buses. An Alpha Call-Up mnemonic entered on the MCDU displays the current value of the associated parameter, including multiple system values where applicable.

Column meaning

How to Read the List

Alpha Call-Up

Mnemonic entered on the MCDU to display the current parameter value.

Source

Originating component and, where applicable, system number.

Parameter Number

Structured as Equipment / System / ARINC Label / SDI.

Unit

Engineering unit used for the displayed parameter.

Parameter

System parameter name associated with the Alpha Call-Up.

Comment

Additional description or interpretation supplied by the list.

Eq / Sys / Lab / SDI

Parameter Number Structure

EqConnected bus equipment identifier — hexadecimal
SysSystem 1, 2 or 3
LabARINC 429 label — octal
SDI00, 01, 10 or 11 source/destination identifier
