Menu terminology

Common CFDS Functions

LLR / PLR

Last/Previous Leg Report: identifies LRUs affected by stored failures.

LRU IDENT

Displays identification / part-number information for system LRUs.

GND SCAN

Runs system monitoring on the ground to help identify a faulty LRU.

CLASS 3

Displays class-3 faults detected during the last flight leg.

SYS CONFIG

Displays system configuration information.

TSD / TEST

System-dependent troubleshooting/test functions available from the BITE menu.
